# 会议管理自动化 Skill — meeting-manager

## 目的
自动从飞书妙记（智能纪要）中提取会议信息，解析后为**每个用户自动创建**专属的「会议管理看板」多维表格，实现零配置开箱即用。

---

## 核心流程
1. **首次运行自动建表** → 为当前用户创建全新的「会议管理看板」
2. 每日自动检索飞书妙记 → 发现新智能纪要
3. 解析纪要内容 → 提取7个字段
4. 填入用户专属的「会议管理看板」→ 会议记录 表
5. 进度字段由用户人工维护

---

## 数据结构（自动创建）

### 表格名：会议管理看板
### 表名：会议记录
| 字段名 | 类型 | 选项 |
|--------|------|------|
| 会议时间 | 日期 | — |
| 会议形式 | 单选 | 定计划 / 周会 / 月度经营会议 |
| 会议主题 | 文本 | 智能纪要标题 |
| 汇报人 | 人员 | — |
| 智能纪要链接 | 超链接 | — |
| 待行动项 | 文本 | 自动从纪要提取 |
| 进度 | 单选 | 待开始 / 进行中 / 已完成 |

---

## 初始化机制
- 每次运行前，检测本地缓存文件 `workspace/cache/meeting_manager_config.json`
- 若无配置，则自动调用 `feishu_bitable_app.create` 创建新表
- 创建成功后，将 `app_token` 和 `table_id` 写入本地缓存
- **每个用户独立建表，互不干扰**

## 触发方式

### 方式 1：每日自动检索（cron）
- 频率：每日 12:00、18:00
- 动作：搜索飞书妙记新智能纪要 → 解析 → 填入用户专属表格

### 方式 2：手动触发
- 用户指令：`处理妙记 <url>` 或 `扫描最新会议纪要`

---

## 解析规则
1. 使用 `feishu_fetch_doc` 读取飞书妙记文档内容
2. 提取结构化信息：
   - **会议时间**：从文档提取日期+时间
   - **会议形式**：按关键词自动分类（定计划/周会/月度经营会议）
   - **会议主题**：智能纪要的标题
   - **汇报人**：文档中的组织者/主持人
   - **智能纪要链接**：原文 URL
   - **待行动项**：从"待办""Action Items"章节提取
3. 构造 fields 对象写入表格

### 会议形式分类规则
| 关键词 | 分类 |
|--------|------|
| 定计划、规划、OKR、季度计划 | 定计划 |
| 月度经营、月会、月度复盘 | 月度经营会议 |
| 周会、周报、周例会、本周、站会 | 周会 |
| 默认 | 周会 |
